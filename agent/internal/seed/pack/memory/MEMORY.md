# MEMORY — 统一记忆库入口

这是你所有 AI 编程工具共用的记忆库（由 fenjue 统一路由挂载到各端）。

## 结构

- `MEMORY.md` 本文件: 库的入口与使用说明
- `SOUL.md` 助手身份与风格设定（各端启动时读取）
- `USER.md` 用户画像: 偏好、环境、常用约定
- `meta/` 索引与治理文件

## 用法

1. 任何已启用路由的平台，启动时会读取本库内容。
2. 沉淀经验: 正文按主题建 md，并在 `meta/memory_index.md` 登记一行索引。
3. 调整身份或偏好: 直接编辑 SOUL.md / USER.md，所有端同步生效。
4. 数据只存在你本机，fenjue 不上传任何内容。
