## 0. 读法

**双面分工。** 本文件是**公开面**：描述这个仓库要往哪走、以及凭什么算做完。用户私有环境里的记忆与技能台账是**私有权威**，本文件只登记聚合口径与指向，**不复制其内容**（隐私与商业信息红线）。

## 3. 后续工作计划

### 3.1 G0 — 已完成（记录，供后续复用）

**做了什么。** 两处缺陷：① 忽略规则把 `//go:embed` 的目标目录整个排除，干净克隆时编译期直接失败（本地因构建脚本先拷贝产物而永不暴露）；② 一条忽略规则用了 shell 的扩展通配写法，git 不支持，实测该规则**完全没生效**，导致构建产物呈半跟踪状态。

**怎么验证的。** 不用「本地能构建」推断。用 `git checkout-index` 把暂存面导出成一个等价的干净克隆，在导出目录里跑构建：

| 场景 | 结果 |
|---|---|
| 保留占位文件 | 构建 **rc=0** |
| 逆操作：删掉占位文件 | **rc=1**，报「目录内没有可嵌入文件」 |
| 还原占位文件 | 构建 **rc=0** |

第三行与第二行构成方向相反的一对，证明那个占位文件是**承重的**，不是装饰。另外冒烟了产物本体：版本号可读，能正确装载全部 9 个平台定义，且对未接入的平台如实报异常而不是静默通过。

**风险与应对。** 已发生的风险是「提交时漏项」：用路径参数限定的提交**静默丢弃**了已忽略路径上的删除，HEAD 树里那个文件仍在。靠 `git ls-tree` 复核发现并补了一笔。**应对：任何删除型改动提交后必须回读 HEAD 树，不能只看 `git status` 干净。**

### 3.10 环境事实（会咬人的两条）

1. **Go 工具链不在 PATH。** 实测 `go` 命令不可直接调用，工具链位于固定绝对路径下（版本 go1.27.0 / windows / amd64）。本地构建脚本已在内部兜底，**CI 配置与安装文档必须同样兜底**。此项曾导致一次错误结论：早期只探测 PATH 就判「未安装」。
2. **git 的行尾转换开启。** 仓库以 LF 存储、检出为 CRLF，属该平台默认行为，接受。

## 5. 预期成果与验收标准

| 任务 | 可复算判据 |
|---|---|
| G0 | `git checkout-index -a` 导出面内构建 rc=0；删占位后 rc=1；还原后 rc=0（**已达成**） |
| G1 | `git remote -v` 非空；首次推送后远端可 `git ls-remote` 取到同一提交；Release 页存在且有资产 |
| G2 | 两个域名均 HTTP 200；两侧产物逐文件哈希全等；任一侧不可达时判 `UNVERIFIED`，不得判通过 |
| G3 | 仓库根存在中英两份 README；三平台安装说明均存在；全仓对个人绝对路径模式扫描**零命中** |
| G4 | 一致性腿正反两向各跑一次（注入差异见红、恢复见绿）；两仓各跑 rc=0 |
| G5 | 权限收紧后，本用户可读、另一用户不可读，两侧均实测 |
| G6 | 四页均可路由进入；真实浏览器跑完端到端；前端产物 gzip 后不超过既定上限 |
| G7 | 可开源档过脱敏扫描零命中；上游引用档每条带来源链接；不公开档不在公开仓出现 |
| G8 | 两个平台各有一条真实会话实测记录；未见记录不得改状态字段 |
| G9 | 界面无硬编码单语残留；中英切换后主要页面文案全量替换 |
| G10 | 三平台产物齐备且可执行；CI 首次运行 `steps > 0`（若 `steps = 0` 说明未拿到执行环境，属阻塞而非失败） |
| G11 | 逐项独立验收，各自有可复算判据 |
| G12 | 两个接口各返回预期结构；未授权请求仍返回 401 |
| G13 | 逐端实测结论落盘；不一致项的处置有记录 |
| G14 | 配置文件内无占位域名残留 |

**全局红线（任何一项破了，本轮不算完成）：**

- 公开仓内出现任何个人绝对路径、身份标识或私有项目名；
- 判据「看起来绿」但从未见过红（未做反向验证）；
- 取不到数被折算成通过；
- 已推送的历史被改写而未走授权。

> 复算：以上判据凡涉及命令的，均在文档中给出可直接执行的形态；凡涉及计数的，给出取值口径与脚本位置。
